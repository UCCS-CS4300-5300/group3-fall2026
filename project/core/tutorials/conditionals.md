## Conditional statements

concept:
An if statement allows a program to make decisions based on whether a condition is true; if the condition is true then the instructions will execute and if it is false then the instructions are skipped.

Blocks available:
if - Checks a condition
zombie - Represents a zombie is present
punch zombie - Will perform punch action

Example:
if zombie
    punch zombie

Common Mistakes:
 - Using an empty condition
 - Not placing the action inside of the if block
