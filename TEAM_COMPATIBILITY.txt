LOCAL/CODESPACES CHECKS (python means your existing Python 3.12 interpreter)
From repository root:
  python -m pip install -r project/requirements.txt -r requirements-quality.txt
  python -m pip check
  python -m unittest discover -s tests -p test_quality_report.py -v
  cd project
  python -m pytest -q
  python manage.py check --settings=config.quality_test_settings
  python manage.py makemigrations --check --dry-run --settings=config.quality_test_settings
For the collector, set DJANGO_SETTINGS_MODULE=config.quality_test_settings:
  macOS/Codespaces/Linux: export DJANGO_SETTINGS_MODULE=config.quality_test_settings
  Windows PowerShell: $env:DJANGO_SETTINGS_MODULE = "config.quality_test_settings"
Then, still inside project/:
  python ../scripts/collect_quality.py core
Close that terminal or unset the variable before normal development. pytest.ini
is already configured for config.settings and discovers tests.py as well as
test_*.py. The CI environment variable selects isolated settings instead.
Do not replace pytest.ini with a generic configuration that omits tests.py.
For Windows without activation use the actual .venv/Scripts/python.exe path;
for macOS/Linux use the actual .venv/bin/python path as in SETUP_REFERENCE.txt.
